# Contributing

- Search first; do not create near-duplicates.
- Use a narrow, action-oriented kebab-case filename.
- Start from `templates/prompt-template.md`.
- Add source URL and license for imports; never remove third-party notices.
- Include normal, missing-context and adversarial tests.
- Remove secrets and unnecessary personal data.
- Do not edit the pinned upstream snapshot; adapt a copy under `prompts/`.
- Run `python3 scripts/validate.py`.
