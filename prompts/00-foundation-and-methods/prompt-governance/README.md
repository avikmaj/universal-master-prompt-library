# Prompt Governance

## Coverage

Prompt standards, metadata, licensing, privacy, security, versioning, approval, deprecation and lifecycle management.

## Recommended prompt families

- Research and evidence synthesis.
- Analysis, diagnosis and option comparison.
- Planning, design and implementation.
- Review, audit and optimization.
- Communication, documentation and training.
- Risk, safety, compliance and decision support.
