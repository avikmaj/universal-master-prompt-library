# Platform Usage

## ChatGPT
Use the project-instructions file and upload the catalog, the relevant collection bundle and only the necessary prompt files.

## Claude
Use `CLAUDE.md` at repository scope. Add only relevant sector prompts as Project knowledge.

## Grok
Use `AGENTS.md` or `GROK.md` for project rules, or paste the selected prompt into a normal chat.

## Generic AI
Copy the complete `## Prompt` block, then provide concrete inputs. Do not paste the whole repository into one context window.
